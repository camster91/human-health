# GitHub Projects board setup

Recommended views once the repository is added to a GitHub Project:

## Fields
- Status: Backlog, Ready, In Progress, Review, Blocked, Done
- Phase: Foundation, MVP, Whole-person fitness, Connected health, Coaching intelligence, Long horizon
- Priority: P0, P1, P2, P3
- Type: Epic, Feature, Task, Research, QA, Security
- Area: Design, Workout Runtime, Coaching, Exercise Graph, Health Data, Platform, Privacy, QA
- Target: Now, Next, Later

## Views
1. Now — Ready/In Progress grouped by Status
2. MVP — Phase=Foundation or MVP
3. Roadmap — grouped by Phase
4. Epics — Type=Epic
5. Blocked — Status=Blocked
6. Design — Area=Design
7. Safety & Privacy — Area=Privacy or Type=Security

Keep speculative 5–10 year work at epic/document level until there is evidence to schedule it.
