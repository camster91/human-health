# Phase definitions

- Foundation: architecture, schema, design system, exercise model, state/persistence
- MVP: complete adaptive workout experience usable in the gym
- Whole-person fitness: core, mobility, bodyweight, cardio, power, balance, capability
- Connected health: health platforms, wearables, provenance, portability
- Coaching intelligence: explainable personalization and multi-goal adaptation
- Long horizon: validated models, extensibility, clinician exports where useful, regulatory review
