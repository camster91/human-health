# Design direction

Use the supplied workout-app reference as visual inspiration, not as the information architecture.

Primary navigation:
- Today
- Train
- Progress
- Coach
- Profile

Live workout mode is a separate focused state with navigation hidden.

Visual principles:
- Light, clean, low-density surfaces
- Orange accent for primary actions, active training, PRs, and progress
- Large rounded cards and generous spacing
- Thumb-friendly controls
- Figma-first reusable components
- Accessible contrast and motion
- Strong state design for offline, loading, stale, warning, error, and success

Today should emphasize the recommended action and allow immediate adaptation for short-on-time, different-gym, low-energy, equipment-unavailable, pain, and end-early scenarios.
