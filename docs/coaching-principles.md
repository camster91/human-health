# Coaching principles

1. Safety and pain override progression.
2. Recovery context can reduce or defer training stress.
3. Preserve the purpose of a session, not rigid exercise names.
4. Prefer minimum effective work over all-or-nothing failure.
5. Progress conservatively from measured performance.
6. Explain every recommendation in plain language.
7. Keep user override available at all times.
8. Never infer machine-to-machine or exercise-to-exercise load equivalence.
9. Do not diagnose conditions, prescribe medication/insulin, or provide injury clearance.
10. Learn from behaviour without making hidden irreversible changes to the user's plan.
