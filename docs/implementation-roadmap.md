# Human Health implementation roadmap — Guide-first refactor

This roadmap implements the canonical Guide-first direction.

Historical Phases 0–5 describe how the current app was built. They remain useful history, but they are no longer the active product roadmap.

See `docs/REFACTOR_PLAN.md` for detailed gates.

## R0 — Source-of-truth reset

- canonical product direction;
- canonical architecture;
- canonical experience system;
- canonical refactor plan;
- issue/roadmap reconciliation;
- no production changes.

## R1 — Current-system inventory

- routes/components;
- storage/data;
- programme engines;
- safety;
- connected health;
- AI;
- native bridges;
- media/assets;
- tests and release gates.

Classify every major subsystem: Preserve / Adapt / Replace / Quarantine / Retire.

## R2 — Guide-first shell

Target IA:

- Today
- Body
- Progress
- Guide
- You

Workout/session mode is immersive.

## R3 — Context + memory

Build:

- BodyProfile;
- DailyState;
- personal rules;
- preferences;
- structured memory/provenance;
- corrections;
- timeline;
- context minimization.

## R4 — AI orchestration

DeepSeek-first, provider-agnostic:

- model gateway;
- coordinator;
- specialist roles;
- structured schemas;
- tool permissions;
- privacy controls;
- deterministic fallback.

## R5 — Programme + safety

Integrate AI proposals with:

- whole-person coverage;
- adaptive daily planning;
- progression;
- recovery;
- minimum useful day;
- safety policy;
- professional escalation.

## R6 — Multimodal experience

Add:

- UI composer;
- exercise media;
- body map;
- charts;
- voice;
- trusted web/media/research adapters;
- contextual maps/weather/route experiences where useful.

## R7 — Long-term intelligence

Add:

- weekly coverage;
- 4–8 week adaptation;
- quarterly review;
- annual review;
- maintenance;
- return-after-gap;
- transparent experiments;
- quality-of-life checkpoints.

## R8 — Optional health/lifestyle modules

Add only when they improve the Guide:

- sleep;
- nutrition/hydration;
- recovery/stress;
- wearable context;
- condition/life-stage-aware safety context.

## R9 — Advanced modalities

After core quality is proven:

- hands-free voice;
- camera rep/tempo assistance;
- improved movement feedback;
- widgets/watch;
- richer outdoor/travel modes.

## Delivery principles

- Simple above, sophisticated below.
- Preserve useful data/engines; refactor accidental product structure.
- One useful action beats a dashboard.
- User rules and safety outrank AI.
- No normal flow requires prompt engineering.
- Build mobile-first, accessible, local-first and offline-tolerant.
- Do not merge/deploy without explicit approval.
