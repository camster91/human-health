# MVP build order

## P0 — Foundation
1. App architecture and technical decisions
2. Core health/training schema
3. Design tokens and component primitives
4. Exercise knowledge graph seed
5. Gym/equipment profiles
6. Starter Upper/Lower program
7. Workout state machine
8. Local-first active-workout persistence

## P1 — Usable gym MVP
9. Today screen
10. Live set logger
11. Rest timer and wake lock
12. Previous workout comparison
13. Exercise swap flow
14. Short-on-time adaptation
15. Different-gym/equipment adaptation
16. Plate calculator
17. Deterministic progression engine
18. Workout history + PRs
19. Post-workout coach summary
20. PWA/offline hardening

## P2 — Whole-person training
21. Core programming
22. Mobility/flexibility programming
23. Pull-up/bodyweight skill trees
24. Cardio targets and sessions
25. Athleticism/power/balance
26. Recovery/readiness check-in
27. Capability map and assessments
28. Adaptive rolling schedule
29. Minimum-effective-day mode
30. Travel/return-from-break modes

## Release gate
- Representative mobile/tablet/desktop QA
- Keyboard and screen-reader basics
- Offline interruption recovery
- Error/sync-state UX
- Privacy/security review
- Analytics and error observability
- Backup/export path
- Production deployment and rollback instructions
